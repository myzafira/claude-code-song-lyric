# 🎤 ร้องเพลงกัน (Easy Song Lyric)

Web app สำหรับค้นหาเนื้อเพลง ต่อคิว แล้วเปิด **ภาพเนื้อเพลงตัวใหญ่ พื้นสะอาด** ให้ทุกคนร้องตาม
ใช้ในงานเลี้ยง หรือร้องตาม YouTube ได้ ออกแบบให้อ่านง่ายในที่แสงน้อย และใช้ง่ายทุกวัย

## ทำอะไรได้บ้าง
- ค้นหาจากชื่อเพลง ชื่อนักร้อง หรือคำค้นอื่น (พิมพ์วรรณยุกต์ผิดก็ยังเจอ)
- ต่อคิวเพลงได้สูงสุด 50 เพลง เลื่อนลำดับ หรือลบออกได้ คิวจำไว้ในเครื่องแม้ปิดหน้าเว็บ
- หน้าร้องเพลงแบบเต็มจอ พื้นดำ, ขยาย/ย่อภาพ, โหมด "พื้นดำ" กลับสีภาพพื้นขาวให้ไม่แสบตา, หน้าจอไม่ดับระหว่างร้อง
- ปุ่ม 👍 อ่านง่าย / 👎 อ่านยาก ให้คนร้องช่วยบอกคุณภาพภาพ
- ค้นไม่เจอ กด "🙋 ขอเพลงนี้" ได้
- บันทึกการใช้งาน (ค้นหา, ค้นไม่เจอ, เข้าคิว, เปิดเล่น, ถูกใจ, ขอเพลง) ลง Notion เพื่อนำไปปรับปรุงฐานข้อมูล

## ข้อมูลอยู่ที่ Notion
| ฐานข้อมูล | ใช้ทำอะไร |
|---|---|
| 🎤 Easy Song Lyric – Lyric Images | รายการเพลงและ URL ภาพเนื้อเพลง |
| 🎤 Easy Song Lyric – Usage Log | บันทึกการใช้งาน |

ช่องสำคัญใน Lyric Images
- **Image URLs**: URL ภาพ เรียงตามหน้า หนึ่งบรรทัดต่อหนึ่งภาพ
- **Status**: `ใช้ได้` / `รอตรวจ` / `ต้องหาใหม่` (เพลงที่ `ต้องหาใหม่` จะไม่แสดงในแอป)
- **Readability** 1-5: ความอ่านง่าย ใช้จัดอันดับผลค้นหา
- **Plays / Likes / Dislikes**: แอปนับให้อัตโนมัติ เพลงที่ Dislikes สูงคือเพลงที่ควรหาภาพใหม่

## ตั้งค่าบน Vercel
1. สร้าง Notion integration ที่ https://www.notion.so/profile/integrations แล้วคัดลอก token
2. ในฐานข้อมูลทั้งสองอันบน Notion กด `•••` → Connections → เพิ่ม integration นั้น
3. ใน Vercel → Project → Settings → Environment Variables ใส่ค่าตาม `.env.example`
   - `NOTION_TOKEN`
   - `NOTION_SONGS_DB`
   - `NOTION_LOG_DB`
4. Deploy ใหม่

ถ้ายังไม่ใส่ `NOTION_TOKEN` แอปจะแสดงเพลงตัวอย่าง เพื่อให้ลองใช้งานได้

## พัฒนาในเครื่อง
```bash
npm install
cp .env.example .env.local   # ใส่ NOTION_TOKEN
npm run dev                  # http://localhost:3000
npm test                     # ทดสอบระบบค้นหา
```
